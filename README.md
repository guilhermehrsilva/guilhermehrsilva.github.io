# guilhermehrsilva.github.io

Portfólio pessoal — https://guilhermehrsilva.github.io

Página estática (`index.html`) mais o logotipo em `gr-logo.png`, sem build.
As únicas dependências externas são as fontes Manrope e IBM Plex Mono, vindas
do Google Fonts. Servida pelo GitHub Pages a partir da branch `main`, raiz do
repositório.

Para editar: mexa em `index.html` e faça push. O Pages republica em ~1 minuto.

Para conferir localmente, basta abrir o arquivo no navegador.
